Tool: SUBFINDER
Subfinder es una herramienta de descubrimiento de subdominios que descubre subdominios válidos para sitios web mediante el uso de fuentes pasivas en línea.
Tambien On-Line: https://shrewdeye.app/tools/subfinder

# instalacion (https://www.kali.org/tools/subfinder/)
sudo apt install subfinder
# para ejecutar SUBFINDER
subfinder -h
subfinder -d nombre-dominio -all -f excepto-subdominio -o fichero-de-salida.txt
subfinder -d example.com -all -o /home/antonio/Descargas/example.dominios.txt

Tool: HTTPX-Toolkit

Ejecuta múltiples sondas para recopilar información sobre dominios, servidores web, URL u otros.
Httpx está diseñado para identificar y analizar las configuraciones de los servidores web, verificar las respuestas HTTP y diagnosticar posibles vulnerabilidades o configuraciones erróneas.

# instalacion (https://www.kali.org/tools/httpx-toolkit/)
sudo apt install httpx-toolkit
# Para ejecutar HTTPX-Toolkit
httpx-toolkit -h
httpx-toolkit -l fichero-urls-de-entrada.txt
httpx-toolkit -l fichero-urls-de-entrada.txt -H "X-HackerOne-Research: tu_usuario" <-- por compliance del programa
cat fichero-urls-de-entrada.txt | httpx-toolkit -o fichero-de-salida.txt
cat /home/antonio/Descargas/example.dominios.txt | httpx-toolkit -o /home/antonio/Descargas/example.live.txt

Tool: LOXS
https://github.com/1hehaq/haq
Comprueba determinadas vulnerabilidades:
- LFI Scanner: Detect Local File Inclusion vulnerabilities.
- OR Scanner: Identify Open Redirect vulnerabilities.
- SQL Scanner: Detect SQL Injection vulnerabilities.
- XSS Scanner: Identify Cross-Site Scripting vulnerabilities.
- ...

# instalacion
git clone https://github.com/1hehaq/loxs.git tools/loxs
cd tools/loxs
python3 -m venv venv             
source venv/bin/activate
python3 -m pip install -r requirements.txt
[pip3 install -r requirements.txt]

# Para ejecutar loxs
source venv/bin/activate
python3 loxs.py

TooL: nmap
observaciones: SOLO estas autorizado a lanzar escaners contra el sitio web: scanme.nmap.org
Guía de referencia de Nmap: https://nmap.org/man/es/index.html
(snap connect nmap:network-control)
(snap connections nmap)

# para ejecutar nmap: arrancar un terminal 
ejemplos:
nmap -sL scanme.nmap.org       <--- Lista los objetivoa a escanear
nmap -O scanme.nmap.org        <--- detecta sistema operativo
nmap -p 20-1024 45.33.32.156   <--- sondea los puertos indicados
nmap -v -A scanme.nmap.org     <--- Habilita la detección de SO y de versión 
nmap -sV -p T:22,80,9929,31337  scanme.nmap.org <--- Sondear puertos abiertos, para obtener información de servicio/versión
nmap –sA 45.33.32.156          <---- Comprobación de Firewall Root
